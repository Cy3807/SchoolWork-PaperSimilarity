## 实现要求

- 代码位于仓库的 3123004519 文件夹，入口 main.py，提供 requirements.txt。
- 命令行接收原文、对照文、答案文件三个路径；答案为 0 到 1 的小数，保留两位。
- 运行程序不联网，不读取词典，不创建缓存或业务日志，只使用指定输入输出文件。
- 至少 10 个用例，验证正常输入、短文本、归一化、文件错误和写入保护；记录分支覆盖率。
- 使用 Ruff 检查代码；通过 cProfile 定位 Python 程序热点，再比较优化前后时间与内存。
- 博客首行给出 GitHub 链接，说明接口、算法、性能、测试及每种异常的目标与对应用例。
- 先完成能运行的基线版本，再测量和优化，按实际进展提交 Git。
- 标题和正文采用简洁课程作业风格，最终保存为博客园草稿，不发布。

## 算法选择

采用字符二元片段的词频余弦相似度。先统一全半角、大小写并去掉空白标点，再统计相邻字符片段。
短于两个字符时退回单字符比较；没有有效字符时给出受控错误。
分数表示字面相似程度，不作为语义抄袭判定，也不声称通过未知的 18 个隐藏测试。
